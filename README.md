# 海派 · 小红书本批物料（GitHub 交接）

给 **WorkBuddy**（或外部运营工具）克隆后直接用。本仓库只含小红书资讯帖物料，不含合同/发票等。

## 怎么用（一句话）

克隆后打开 `STATUS.md` 找今天「待发」→ 打开 `posts/` 对应 md 复制标题/正文/话题 → 配 `covers/` 同序号封面图 → 老板在小红书 App 点发布；发完把笔记链接回填状态。

## 目录

```
README.md       本说明
QA_CHECKLIST.md 交付前质检清单
HANDOFF.md      角色分工、口径、日常流程
STATUS.md       发布状态表（Markdown）
STATUS.csv      同上（CSV，方便表格工具）
overview.md     本批「一帖一包」总览
posts/          10 篇成稿（标题+正文+话题+首评+合规）
covers/         9 张封面（13 号暂无，其余与 posts 同序号对应）
```

## 交付前质检

所有交给老板或总控的 PR、报告，运营先按 [`QA_CHECKLIST.md`](QA_CHECKLIST.md) 逐条核对，并在 PR 描述或报告末尾附勾选结果；不通过的退回获客，不转老板。

## 口径（务必遵守）

- **港校优先**；冷启动前两周 **纯资讯、弱硬 CTA**
- 结尾最多一句轻触达；评论置顶偏补充资讯
- **禁止**：失业率、保录、保证签证、代写代投、身份代办/高才包过等承诺
- **不代发、不代回私信**；成稿大改找总控/获客
